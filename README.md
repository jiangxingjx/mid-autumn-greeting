# 🌕 中秋节祝福前端 Demo

一个精美的中秋节祝福网页，输入名字即可生成专属中秋祝福。

## ✨ 功能特点

- 输入名字，生成专属中秋节祝福语
- 精美的夜空星空背景动画
- 月亮发光动效
- 玉兔和灯笼装饰
- 响应式设计，支持移动端
- 玻璃拟态 UI 风格

## 🚀 使用方法

1. 打开 `index.html` 文件
2. 在输入框中输入你的名字
3. 点击「送出祝福」按钮
4. 查看专属中秋祝福

## 🎨 技术栈

- HTML5
- CSS3 (动画、渐变、玻璃拟态)
- 原生 JavaScript
